Design notes

This pass makes what is already built look and read better. It adds no new functions and removes none. Anything new is listed as Phase 2 in the handover.

  1. Four modes, as built

    Resource, Capacity, Project and Breakdown (working title for the Workload Balancer) as an always-visible switch. The range is its own control.

  2. Two toolbar rows

    Row 1 is where and when, plus the actions. Row 2 is the view: everything a saved view keeps.

  3. Filter chips as built

    Set Is / Is not and And / Or in the filter picker. Chips show them as labels. When the bar fills, a count shows the rest; click it to see them all.

  4. RAG as built

    A thin bar on the top edge of every person row, on each booked day: green on target, amber under, red over. The site sets where green starts (100% by default). RAG Indicator decides FTE or Target Billable.

  5. Pencils queue

    Overlapping pencils on one person are numbered in the order they were made. Róisín Doyle has two in the week of 26 Oct.

  6. Leave is a booking

    Annual Leave, Training and Travel are bookings on event projects. They sit beside other bookings, count as booked hours and have every booking action. Hatched as a style.

  7. Holidays are per person

    Each person’s holiday calendar greys their own day, like a weekend. Hover for its name. Lucía Romero is on the Spanish calendar.

  8. One booking window, no window on top

    Hours per day, Distribute and Smart resourcing open as panels under their row. Confirms sit in the footer.

  9. Right-click keeps every action

    The booking window has the same actions. Both routes stay.

  10. Project planner

    Footer › Project planner shows the Resource Planner tab inside a project: Project Team, the This project Display group and the Unassigned Bookings strip.
