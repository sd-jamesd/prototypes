Dynamic Loader — states

v0.5 · 2026-07-29

Generic loader for any queued action where the user chooses to wait. Two triggers live today (a tasks trigger and an AI trigger); the copy stays object-agnostic so it serves any of them. Updates in place and auto-refreshes on completion, with a close-and-notify escape. Step through states in the live preview; the handoff below has the copy strings to pull verbatim.

Full failure only, no count. The backend reports that the action failed, not which parts, so there's no tally and no per-item recovery. Single Retry re-runs the whole thing. Confirm a retry can't duplicate a partial run before wiring.
