Maps to position:

Highest-risk state — nothing visibly happens until the job starts. The ticking position is what proves it's alive. If position can't be resolved, fall back to Large imports can take a few minutes. and keep the spinner.

Default version, since the count isn't available mid-import. Indeterminate spinner, no progress bar. The rotating line must keep moving — a static line on an infinite spinner reads as hung. No "almost there" copy: don't imply imminent completion the system can't confirm.

Title
Import finished with errors
Tally
{added} of {total} tasks added. {failed} couldn't be imported.
Body
Retry the {failed} that failed, or review what went wrong.
Actions
Review errors (primary) · Retry {failed} failed — retry is scoped to the failed rows only.

Reference implementation of the partial-failure pattern (PR-011). Viable here because the import backend reports counts, so it can report which rows failed. Retry acts only on the failed set. This is the pattern the system-wide queued-actions spec inherits — the estimate queue couldn't support it, this can.
